# Tools

Small client-side tools from [Works On My Bench](https://worksonmybench.dev/tools/). Each folder is a self-contained static page with no build step and no dependencies: open its `index.html` in a browser, or host the folder anywhere.

| Tool | What it does |
|---|---|
| [`shelfcalc`](shelfcalc/) | Cut list, shopping list, cutting diagrams and runner heights for a ladder-frame box storage rack |

Each tool's README covers its model and how to embed it.
