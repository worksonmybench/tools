Runner heights (to check with a tape)

Heights are from the floor, and the "top end" column measures down from the upright's top end. Use the spacer between each runner and its neighbor to set the next one (top down: spacer above the new runner; bottom up: below). Check against these every 3–4 rows. If you're more than about 1/8" off, correct on the next runner.

Lumber sizes use standard actual dimensions (1× = 3/4" thick, 2× = 1 1/2", 3" nominal = 2 1/2" wide). The diagonal is an estimate, so mark it in place before cutting. Weight assumes dry lumber, and wet lumber can be 20–30% heavier.
